# 答辩示例图片文件夹

本文件夹用于存放毕业设计/课程设计答辩时需要在 PPT 中插入的系统截图。

## 建议放入的截图

### 前台页面
1. **首页轮播图** - 展示轮播图效果和热门商品
2. **商品列表页** - 展示分类筛选和分页功能
3. **商品详情页** - 展示商品信息、加入购物车
4. **购物车页** - 展示购物车管理和总价计算
5. **结算页** - 展示下单流程
6. **订单列表页** - 展示订单状态流转
7. **用户登录/注册页**

### 后台页面
8. **管理后台首页/仪表盘**
9. **商品管理页** - 展示列表、新增、编辑
10. **分类管理页**
11. **用户管理页** - 展示启用/禁用功能
12. **订单管理页** - 展示发货操作

### 技术架构图
13. **系统架构图** (SSM 三层架构)
14. **数据库 ER 图**
15. **核心业务流程图**

### 项目结构
16. **项目目录结构截图**
17. **Maven 依赖截图**
